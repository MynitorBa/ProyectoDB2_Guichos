# E11 · Elasticsearch caído durante una compra

**Resultado: ✅ superado** — generado por `backend/scripts/demo_fallas.py` contra el sistema en ejecución.

| | |
|---|---|
| Falla | Elasticsearch detenido (`docker stop tiendaya_elasticsearch`) |
| Cómo se provocó | Se detiene Elasticsearch, se compra, se espera y se vuelve a arrancar. |
| Comportamiento esperado | La compra se confirma igual (MySQL es la autoridad); los eventos hacia Elasticsearch esperan en el outbox con backoff y convergen al volver el servicio, sin afectar a los demás destinos. |
