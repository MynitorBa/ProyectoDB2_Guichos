# E12 · Neo4j caído durante una compra

**Resultado: ✅ superado** — generado por `backend/scripts/demo_fallas.py` contra el sistema en ejecución.

| | |
|---|---|
| Falla | Neo4j detenido (`docker stop tiendaya_neo4j`) |
